# Code of conduct

Fastmash adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies in the repository, issues, pull requests,
discussions and any other project space.

In short: be respectful and constructive, assume good faith, and focus on the
work. Harassment, personal attacks and discriminatory language are not
acceptable.

## Reporting

To report behavior that violates the code of conduct, contact the maintainer
privately through <https://pederbe.dev/#contact>. Reports are handled
confidentially. The maintainer may remove content, or warn, suspend or ban
participants, following the Contributor Covenant's enforcement guidelines.
