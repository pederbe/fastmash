# Contributing

Help improve Fastmash by reporting bugs, sharing real workloads, improving
documentation or contributing code. The
[contribution guide](https://github.com/pederbe/fastmash/blob/main/CONTRIBUTING.md)
covers development setup, checks and pull requests.

[Design decisions](https://github.com/pederbe/fastmash/blob/main/docs/src/adr/index.md)
explain the constraints behind the implementation.

Report security problems through the
[security policy](https://github.com/pederbe/fastmash/blob/main/SECURITY.md).
