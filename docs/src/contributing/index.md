# Contributing

Fastmash welcomes contributions: bug reports, compatibility findings,
benchmarks from real workloads, documentation fixes and code.

Start with the
[contribution guide](https://github.com/pederbe/fastmash/blob/main/CONTRIBUTING.md)
in the repository. The pages in this section explain how Fastmash is built:

- [Architecture](architecture.md): crates, the path of a command, sorting,
  numbers, errors and safety
- [Testing](testing.md): the test layers and how to run them
- [Glossary](glossary.md): the project's vocabulary
- [Decision records](../adr/index.md): the decisions that shape the design
