From raw exports to useful answers

More of your workflow, in one command

Keep familiar field selectors and grouping. Add the tools that make daily table work easier.

01 / REPORT

CSV in. Named results out.

Read quoted fields with commas and line breaks. Write CSV reports with stable column names, grouping and weighted means.

fastmash --csv -H -s -g region \
  --result-name=1:average \
  wmean price:units < sales.csv
CSV and result names

02 / INSPECT

Understand your table.

See widths, missing values and mixed types. Validate the rules you supply, or keep the highest and lowest complete records with stable ties.

fastmash --header-in health \
  type price number \
  nonmissing id validate < sales.tsv
Table health Highest and lowest records

03 / COMPARE

See what changed.

Align summaries from two datasets, even when headers move. Rank absolute or percentage changes, with added and removed keys still visible.

fastmash --csv -H -g region \
  compare before.csv after.csv \
  rank 1 percent limit 10 sum revenue
Dataset comparison

4.2× on RefGene quartiles

Speed relative to GNU datamash 1.9 on selected core jobs. Two native Linux machines, the same data and output, exact release binaries.

* Six named host/job comparisons are slower: disk-spilling sorts, Intel many keys and Intel distinct-value geometric mean. Three further comparisons are inconclusive. All results and the method

And better in other ways

Portable arithmetic, built-in locale data and clear handling of inputs that GNU datamash 1.9 cannot safely process.

GNU datamash 1.9Fastmash
Results Depend on the CPU and the C math library Identical on every machine: all arithmetic in software
Locales Need locale data installed; silently fall back to C without it Built in: numbers in 318 locales, sorting in 194
perc:100 Can read past the end of the values Returns the largest value
rmdup on several keys Crashes on an assertion A clear refusal
Malformed parameters such as strbin:2.0 Misleading errors or undefined behavior An accurate error message
crosstab labels over 511 bytes Truncated Kept in full

Keep the commands you know

GNU datamash's operations, options, field selectors, grouping and headers. Most scripts can switch by changing the program name; the migration guide covers the documented differences.

Migrating from datamash 
- datamash -t, -s -g 1 mean 3 sstdev 3 < sales.csv
+ fastmash -t, -s -g 1 mean 3 sstdev 3 < sales.csv
