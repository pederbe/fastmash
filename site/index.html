Fastmash is faster than GNU datamash*

The datamash commands you already know, over 70 operations and modes: sums, quantiles, grouping, crosstabs and more. Written in Rust, up to 4× faster on real jobs.

curl -fsSL https://fastmash.io/install.sh | sh

Installs the latest release into ~/.local/bin after checking its checksum.

cargo install --locked fastmash

Builds from source with your Rust toolchain.

cargo binstall fastmash

Downloads the prebuilt release binaries with cargo-binstall.

curl -LO https://github.com/pederbe/fastmash/releases/download/v@VERSION@/fastmash_@VERSION@_amd64.deb && sudo apt install ./fastmash_@VERSION@_amd64.deb

The .deb package for Debian 10, Ubuntu 20.04 and newer.

sudo dnf install https://github.com/pederbe/fastmash/releases/download/v@VERSION@/fastmash-@VERSION@-1.x86_64.rpm

The .rpm package for Fedora, RHEL 8 and newer.

Up to four times faster

Times faster than GNU datamash 1.9 on the core jobs, on two machines. Same data, same output, release binaries.

* In 0.1.0, some disk-spilling sorts and the distinct-value geometric-mean job are slower on native Linux. All results and the method

And better in other ways

Where GNU datamash 1.9 guesses, crashes or depends on the machine, Fastmash doesn't.

GNU datamash 1.9Fastmash
Results Depend on the CPU and the C math library Identical on every machine: all arithmetic in software
Locales Need locale data installed; silently fall back to C without it Built in: numbers in 318 locales, sorting in 194
perc:100 Can read past the end of the values Returns the largest value
rmdup on several keys Crashes on an assertion A clear refusal
Malformed parameters such as strbin:2.0 Misleading errors or undefined behavior An accurate error message
crosstab labels over 511 bytes Truncated Kept in full

Switching is one word

Same operations, options, field selectors, grouping, headers and output. Keep your scripts and change the program name.

Migrating from datamash 
- datamash -t, -s -g 1 mean 3 sstdev 3 < sales.csv
+ fastmash -t, -s -g 1 mean 3 sstdev 3 < sales.csv

Fastmash is free software under MIT OR Apache-2.0. It contains no GNU datamash code.
